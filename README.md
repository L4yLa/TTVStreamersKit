# TTVStreamersKit

Beat Saber 配信者向けの MOD です。
Twitch のチャットの表示、曲のリクエスト、エモートの演出表示の機能を含みます。

Twitch との接続には [TTVCore](https://github.com/L4yLa/TTVCore) を使います。

## 依存 MOD

- BSIPA
- BeatSaberMarkupLanguage
- SiraUtil
- CameraUtils
- SongCore
- TTVCore

## クレジット

- 以下の MOD を参考に制作しています。
  - EnhancedStreamChat（denpadokei）
  - SongRequestManagerV2（angturil、denpadokei）
  - ChatEmoteParticles（L4yLa）
- チャットのフォントは [BIZ UDPGothic](https://github.com/googlefonts/morisawa-biz-ud-gothic)（SIL Open Font License 1.1）から作っています。
